### 3. 主控引脚自动分配 ✅
**文件**: `src/ui/config_panel.py`

添加了 `⚡ 自动分配引脚` 按钮和 `_auto_assign_pins()` 方法：

**功能**：
- 选择主控后，点击按钮自动按顺序分配引脚
- 前 N 个引脚分配给行（ROWS）
- 后 M 个引脚分配给列（COLS）
- 自动检测引脚是否足够
- 分体键盘会预留通信引脚

**分配逻辑**：
```
RP2040 (30个可用引脚)
矩阵 6行×6列 = 12个引脚
分体通信 = 2个引脚（TX/RX）
剩余 = 16个引脚（可用于RGB/编码器/OLED等）

分配结果：
行引脚：GP0-GP5
列引脚：GP6-GP11
通信：GP12(TX), GP13(RX)
```

### 4. 32U4/RP2040 分体通信优化 ✅
**文件**: `src/core/mcu_db.py`, `src/ui/config_panel.py`

更新了 `SPLIT_SERIAL_PRESETS`，区分单线和双线方案：

#### **ATmega32U4（单线推荐）**
```
方案1（推荐）：单线半双工
- 驱动：bitbang
- 引脚：PD0（TX和RX共用）
- 接线：TRRS 4芯线 → VCC/GND/Data/NC
- 说明：TX和RX使用同一引脚，节省IO口
```

#### **RP2040（双线推荐）**
```
方案1（推荐）：双线全双工
- 驱动：vendor
- 引脚：GP0(TX) + GP1(RX)
- 接线：TRRS 4芯线 → VCC/GND/TX/RX
- 说明：左右分别刷写固件，速度更快
```

**改进点**：
- 添加了详细的接线说明
- 明确了单线/双线的区别
- 提示左右分别刷写固件的方案
