# 测试指南

## 快速测试新功能

### 1. 测试 KLE 标签自动赋值

**测试用 KLE JSON**（标准 QWERTY 布局）：
```json
[
  ["Esc","1","2","3","4","5","6","7","8","9","0","-","=","Backspace"],
  ["Tab","Q","W","E","R","T","Y","U","I","O","P","[","]","\\"],
  ["Caps","A","S","D","F","G","H","J","K","L",";","'","Enter"],
  ["Shift","Z","X","C","V","B","N","M",",",".","/","Shift"],
  ["Ctrl","Win","Alt","Space","Alt","Win","MO(1)","Ctrl"]
]
```

**操作步骤**：
1. 运行 `python main.py`
2. Step 1：点击「📋 粘贴 KLE JSON」
3. 粘贴上述 JSON
4. 点击「⚡ 自动分配矩阵」
5. 进入 Step 2：Keymap 编辑
6. 检查 Layer 0 的键值是否正确：
   - Q → KC_Q
   - Space → KC_SPC
   - MO(1) → MO(1)

---

### 2. 测试引脚自动分配

**操作步骤**：
1. 完成 Step 1 和 Step 2
2. 进入 Step 3：配置 & 导出
3. 切换到「主控 & 引脚」标签页
4. 选择主控：RP2040
5. 点击「⚡ 自动分配引脚」
6. 检查结果：
   - 行引脚：GP0-GP4（5行）
   - 列引脚：GP5-GP18（14列）

---

### 3. 测试分体通信配置

**操作步骤**：
1. Step 1：选择「分体键盘」
2. 导入 DM56 的 KLE JSON（或任意分体布局）
3. 自动分配矩阵
4. Step 3：切换到「分体通信」标签页
5. 选择主控：RP2040
6. 查看「推荐预设」下拉框：
   - 应显示「双线全双工（VCC+GND+TX+RX）推荐」
7. 选择该预设，检查：
   - 串口驱动：vendor
   - TX 引脚：GP0
   - RX 引脚：GP1
   - 说明：显示接线方式

**测试 32U4 单线方案**：
1. 选择主控：ATmega32U4
2. 查看「推荐预设」：
   - 应显示「单线半双工（VCC+GND+1引脚）推荐」
3. 选择该预设，检查：
   - TX 引脚：PD0
   - RX 引脚：PD0（与TX相同）
   - 说明：TX和RX使用同一引脚

---

### 4. 测试键码分类

**操作步骤**：
1. Step 2：Keymap 编辑
2. 点击任意键帽
3. 查看底部键码面板的标签页：
   - Basic
   - ISO/JIS
   - Modifiers
   - Quantum
   - Layer
   - Mod-Tap
   - Media
   - Numpad
   - Functions
   - Lighting
   - Mouse

4. 切换到「Layer」标签页，检查是否包含：
   - MO(1) ~ MO(7)
   - TG(1) ~ TG(4)
   - TO(0) ~ TO(3)
   - LT(1,KC_SPC)

5. 切换到「Media」标签页，检查是否包含：
   - KC_MUTE, KC_VOLU, KC_VOLD
   - KC_MPLY, KC_MSTP
   - KC_WSCH, KC_WHOM（浏览器控制）

### 5. 完整流程测试

**目标**：从 KLE 导入到固件导出

1. **Step 1**：
   - 导入上述 QWERTY KLE JSON
   - 选择「整体键盘」
   - 自动分配矩阵
   - 检查底部矩阵总览表

2. **Step 2**：
   - 检查 Layer 0 键值是否正确
   - 切换到 Layer 1
   - 为几个键设置功能键（F1-F12）
   - 添加一个 Layer 2，设置媒体键

3. **Step 3**：
   - **基本信息**：填写键盘名称 "test_kb"
   - **主控 & 引脚**：选择 RP2040，自动分配引脚
   - **功能模块**：勾选「多媒体键」和「全键无冲」
   - **Vial 配置**：生成 UID，设置层数为 3

4. **导出**：
   - 点击右侧「📦 导出固件文件夹」
   - 选择输出目录
   - 检查生成的文件：
     - `test_kb/keyboard.json`
     - `test_kb/keymaps/vial/keymap.c`
     - `test_kb/keymaps/vial/vial.json`

5. **验证**：
   - 打开 `keymap.c`，检查 Layer 0 是否包含正确的键码
   - 打开 `vial.json`，检查矩阵尺寸和布局

## 常见问题排查

### Q1: KLE 标签没有自动识别？
**检查**：
- 标签是否在 `LABEL_TO_KEYCODE` 映射表中
- 尝试大小写不敏感匹配（如 "space" → KC_SPC）
- 单字母应自动识别（如 "q" → KC_Q）

### Q2: 自动分配引脚后显示「引脚不足」？
**原因**：矩阵尺寸超过主控可用引脚数
**解决**：
- 减少矩阵行列数
- 更换引脚更多的主控（如 RP2040）

### Q3: 分体通信预设没有显示？
**检查**：
- 是否在 Step 1 选择了「分体键盘」
- 主控是否支持分体通信（32U4/RP2040/STM32）

### Q4: 导出后编译失败？
**检查**：
- 引脚是否有冲突（同一引脚分配给多个功能）
- 矩阵坐标是否有重复
- 键码是否有拼写错误
